# 数据可视化验证判定标准

数据集可视化后，按以下标准判定数据是否"正常"或"异常"。

## 图像 + 标注叠加可视化

### 正常指标
- bbox 紧密包围目标物体，无明显偏移
- segmentation mask 边缘与物体轮廓基本吻合
- 标注类别与图像中实际物体一致
- 不同类别用不同颜色标注，可区分

### 异常信号
- **bbox 偏移**：框与物体位置明显不对应 → 可能坐标格式错误（如 xywh vs xyxy）
- **bbox 超出图像边界**：坐标值超过图像宽高 → 坐标未做裁剪或归一化方向错误
- **标注全部集中在左上角**：→ 未做归一化还原（如 YOLO 格式未乘以宽高）
- **标注全部集中在图像外**：→ 坐标系不匹配（如像素坐标被当作归一化坐标）
- **类别标注错误**：框内物体与标签文字不一致 → 类别 ID 映射错误
- **无标注显示**：图像上完全看不到标注 → 标注文件未正确读取或路径不对

## 类别分布统计

### 正常指标
- 每个类别都有样本（无零样本类别）
- 类别分布虽有不平衡但无极端长尾（最多类 vs 最少类 < 100:1）
- 总样本数与预期一致

### 异常信号
- **某类别样本数为 0**：→ 类别 ID 映射错误，或数据筛选遗漏
- **某类别样本数远少于预期**：→ 标注缺失或文件过滤条件错误
- **极端不平衡（>100:1）**：→ 考虑过采样/加权采样/focal loss，并提醒用户
- **总样本数与预期差异大**：→ 数据路径配置错误，或文件格式不被识别

## 标签完整性检查

### 必须检查项
- [ ] 每张图像都有对应标签文件
- [ ] 每个标签文件都非空（除非确实是背景图）
- [ ] 标签中的类别 ID 都在有效范围内（0 ~ num_classes-1）
- [ ] bbox 坐标在合理范围内（归一化值在 0-1，像素值在 0-图像尺寸）
- [ ] 图像文件可正常打开（无损坏文件）

### 建议检查项
- [ ] 图像尺寸统计（是否统一，或差异范围）
- [ ] 每张图中标注数量分布（是否有异常多/少标注的图）
- [ ] 标签文件编码（UTF-8 / ASCII）
- [ ] 空白图像检查（全黑/全白）

## 点云数据（如适用）

### 正常指标
- 点云着色后能清楚看到场景结构
- 语义标签着色后不同类别区分明显
- 实例标签着色后同类不同个体可区分
- 点数密度在合理范围

### 异常信号
- **点云显示为一条线或一个点**：→ 坐标单位可能错误（如米 vs 厘米）
- **所有点同一颜色**：→ 语义标签未正确加载或全为同一类
- **大量孤立噪点**：→ 点云未做滤波预处理
- **空场景（极少点）**：→ 文件损坏或路径错误

## 可视化输出目录结构

```
data_check/
├── visualize/              # 可视化图像（随机抽样 20-50 张）
│   ├── train_0001.jpg
│   ├── train_0002.jpg
│   └── ...
├── class_distribution.png  # 类别分布柱状图
├── label_stats.json        # 标签统计数据（JSON 格式）
├── anomaly_report.md       # 异常报告
└── convert_dataset.py      # 格式转换脚本（如需要）
```

## 判定流程

```
1. 查看 visualize/ 中的可视化图像
   → 标注位置正确？类别正确？
   → 正常 → 继续
   → 异常 → 检查坐标格式 / 类别映射

2. 查看 class_distribution.png
   → 分布合理？无零样本？
   → 正常 → 继续
   → 异常 → 检查数据路径 / 标注文件

3. 查看 anomaly_report.md
   → 无严重异常？
   → 正常 → 数据准备完成，进入阶段 5
   → 异常 → 按报告逐项修复
```
